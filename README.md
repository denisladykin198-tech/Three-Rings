# Три Кольца (Three Rings)

Этот проект начинался как небольшая игра для партии с другом, но в процессе разработки превратился в полноценный демонстрационный масштабируемый, многопользовательский игровой сервер без использования тяжелых фреймворков вроде Tokio, Actix, Axum или Serde, полагаясь только на стандартную библиотеку Rust.

## Особенности проекта

### Геймплей
- 3 концентрических кольца с разными зарплатами и ценами.
- Специальные клетки, позволяющие игрокам переходить между кольцами, меняя стратегию.
- ИИ с тремя уровнями сложности, умеющий оценивать активы, торговаться и объявлять банкротство.
- Два режима: полноценный онлайн через WebSocket и локальный Hot-Seat (офлайн) на одном устройстве.

### Backend
- std only: Сервер написан исключительно на стандартной библиотеке. Многопоточность (`Arc`, `Mutex`, `Condvar`), работа с сокетами и управления памятью без скрытых аллокаций фреймворков.
- Серверная логика (`main.rs`, `room.rs`, `net.rs`) ничего не знает о правилах игр. Вся механика инкапсулирована за трейтом `Game` (`mod.rs`). Чтобы добавить новую игру (например, "Крестики-нолики" или покер), достаточно реализовать этот трейт и добавить одну строку в реестр.
- Ручная реализация рукопожатия (handshake), маскирования фреймов, пинг/понг и фрагментации в строгом соответствии с RFC 6455.
- Собственный легковесный билдер JSON (`struct J`), который формирует строки без аллокаций и зависимостей вроде `serde_json`.
- Кастомный генератор псевдослучайных чисел (splitmix64) с сидом, что позволяет воспроизводить состояния и гарантирует честность бросков кубиков.

### Frontend
- Весь клиент (HTML, CSS, JS, SVG-графика и даже процедурная генерация звука) упакован в один файл `index.html`. Никаких Webpack, Vite, React или внешних зависимостей.
- Все звуковые эффекты (бросок кубиков, покупка, банкротство) генерируются процедурно через осцилляторы в реальном времени. Никаких внешних `.mp3` файлов.
- Игровое поле масштабируется под любой экран, сохраняя четкость, с кастомными анимациями перемещения фишек и частиц (Canvas API).

## Как запустить

Для запуска не требуется ничего, кроме установленного компилятора Rust.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/three-rings.git
   cd three-rings
   ```
2. Скомпилируйте и запустите сервер (по умолчанию порт `3000`):
   ```bash
   cargo run --release
   ```
3. Откройте браузер и перейдите по адресу:
   - Локально: `http://localhost:3000`
   - В локальной сети: `http://<ВАШ_LOCAL_IP>:3000` (сервер автоматически определит ваш LAN IP и выведет его в консоль).

## Почему этот проект выделяется? (Для рекрутеров)

1. Вместо сборки проекта из 20 готовых крейтов, здесь продемонстрировано умение работать "под капотом": ручное управление байтами в сетевых фреймах, атомарные операции, блокировки и условные переменные (`Condvar`) для эффективного пробуждения потоков.
2. Ядро сервера зависит только от абстракции (`dyn Game`), а не от конкретных реализаций. Это делает код тестируемым и расширяемым.
3. Отсутствие парсинга JSON через `serde` в hot path сервера снижает нагрузку на аллокатор и повышает пропускную способность.
4. Проект показывает способность довести идею от сетевой архитектуры до пиксель-перфектного, анимированного UI с процедурным звуком без использования фреймворков.
